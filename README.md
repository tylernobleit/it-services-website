# IT Services Website Template

A complete multi-page marketing site for a mobile tech-repair and IT support company, built with plain HTML, CSS and JavaScript so it hosts anywhere for free.

All names, phone numbers, emails, locations and analytics IDs in this copy are placeholders.

## What's included
- **Core pages:** home, about, services overview, contact with quote request form, reviews, business services.
- **Service pages:** phone, tablet, computer, Mac, gaming, setup and support, networking and security, website design.
- **Local landing pages:** one page per service area, written for local search.
- **Blog:** nine how-to posts (slow computer, Wi-Fi speed, phishing texts, phone battery health, water damage and more).
- **Site assistant:** a rule-based FAQ chatbot (`assets/chatbot.js`) that answers common questions with no backend or cost.
- **Legal pages:** privacy, terms, cookies, website policy.
- **SEO:** page titles and descriptions, Open Graph tags, JSON-LD LocalBusiness structured data, sitemap and robots.txt.
- **Responsive and mobile-first**, with SVG icons and illustrations.

## Tech
HTML5, CSS3, vanilla JavaScript. Netlify-ready, with `_headers` and `_redirects` for security headers and routing.

## Customize
1. Search and replace the placeholder business name, phone, email and city names.
2. Update the JSON-LD block in `index.html` and `contact.html`.
3. Put your own analytics ID in place of `G-XXXXXXXXXX` and connect the quote form to your form handler.
4. Deploy the folder to Netlify, GitHub Pages or any static host.
